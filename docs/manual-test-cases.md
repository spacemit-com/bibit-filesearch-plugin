# bibit-filesearch 功能自测用例表

手工自测（GUI 为主）。被测对象：宿主设置页「文件检索」插件 + 后端 `bibit-filesearch` 服务。
结果列留空待填，勾选「通过」或「失败」，失败请在备注写现象并附最小复现命令。

## 一、被测版本与环境前置

| 组件 | 版本 / 位置 | 就绪判据 |
|---|---|---|
| 宿主应用 | BiBit 桌面版 | 桌面可启动，**设置 → 功能**里存在「文件检索」 |
| 插件 | bibit-filesearch-plugin `0.1.0` | 设置 → 功能 可见「文件检索」 |
| 服务 | bibit-filesearch `0.1.24` | `curl http://127.0.0.1:18700/health` → `{"code":0,...,"status":"ok"}` |
| 向量化 | embed 端点 `:18790`（OpenAI 兼容）| `curl http://127.0.0.1:18700/health/deep` → `"embed":"ok"`（响应里 `embedUrl` 即网关地址）|
| 登录用户 | 任一普通桌面用户 | 服务为 per-user 服务，须登录后才有 |

开工前：

```bash
# 备份用户配置，测完恢复
cp ~/.config/bibit-filesearch/config.yaml ~/.config/bibit-filesearch/config.yaml.bak
# 确认服务与索引底座
sudo -u bianbu XDG_RUNTIME_DIR=/run/user/1000 systemctl --user status bibit-filesearch
curl -s http://127.0.0.1:18700/health/deep
```

## 二、测试数据准备

放进 `~/Desktop/fs-testdata/`（可整体替换成任意自备资料目录）：

```bash
D=~/Desktop/fs-testdata && mkdir -p "$D"/{sub1/sub2,skipme}
printf 'GPU 纹理压缩使用 ASTC 与 ETC2 格式。\n' > "$D"/cn-sample.txt
printf '# Texture compression\n\nPowerVR supports ASTC 4x4 only.\n' > "$D"/en-sample.md
printf 'def render():\n    pass\n' > "$D"/sample.py
printf '{"k": 1}\n' > "$D"/sample.json
printf 'echo hi\n' > "$D"/sub1/sub2/deep.txt      # 用于索引深度用例
printf 'should be excluded\n' > "$D"/skipme/no-index.txt  # 用于排除规则用例
```

其余格式（docx / xlsx / pptx / pdf / 含文字的 png·jpg）请手工放入真实文件，可直接用桌面已有的文档，或新建后另存为对应格式。图片 OCR 用例需要图中文字清晰可辨。

## 五、已知限制（非缺陷）

| 现象 | 原因 | 处理 |
|---|---|---|
| 「功能」分组里「文件检索」首屏为英文 | 宿主懒注册插件词条，进过页面后才切到当前语言 | 页面内文案不受影响；属宿主行为 |
| 图片检索较慢 | OCR 逐图识别 | 只勾需要的格式；不勾选则图片文字搜不到 |
| 超大文档索引失败 | 向量化请求 60s 超时 | 属已知限制，后端单独登记 |
| 界面无检索分页 | 未实现分页控件；一次取满返回条数（前端上限 100 条）| Top-K 决定返回条数上限。**注意**：Top-K 设到 100 以上时列表仍只显示 100 条（前端单次取数上限）|
| 语义门槛挡不住无关结果 | **标定失效**（噪声与真实命中的分数区间重叠，不存在可用的单一阈值）| 已知问题，见 [`acceptance.md`](acceptance.md) 第 4 节；不要依赖它过滤噪声 |

## 六、缺陷反馈格式

发现失败项时按此提交，便于直接复现：

```
用例编号：B5
现象：排除规则加了 skipme，保存并索引后检索 "excluded" 仍命中
最小复现：
  1) echo "should be excluded" > ~/Desktop/fs-testdata/skipme/no-index.txt
  2) 排除规则填 skipme → 保存并索引
  3) 检索 excluded
预期：无结果
实际：返回 1 条 .../skipme/no-index.txt
环境：bibit-filesearch 0.1.24 / 插件 0.1.0 / 宿主 BiBit
```
